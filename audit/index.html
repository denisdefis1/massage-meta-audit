02 Key Audit Insights только то, что влияет на стратегию
✅
Что работало
Лучшие кампании: $1.19–$2.20/диалог. Objective OUTCOME_ENGAGEMENT → Conversations — правильная механика. Instagram Feed — основной рабочий плейсмент. First reply rate 84.9% — команда отвечает хорошо.
🔴
Главная проблема
С апреля 2026: CPD вырос с $2 до $8–13 — алгоритмическая усталость + отсутствие новых креативов. Весь трафик — бусты органики, ни одного purpose-built креатива.
⚡
Ключевой сигнал
Мужчины 35–54: $1.51–$2.85/диалог при 247 диалогах. Женщины того же возраста: $5–11/диалог. Сегмент мужчин хронически недофинансирован — нет ни одного мужского креатива.
📌
Структурная проблема
89 ad sets на интересах, только 7 — LAL. Бюджет дробился неэффективно. Решение: broad + Andromeda + creative diversity вместо микросегментации.

05 Meta Andromeda Approach
Принцип: Broad audience + Creative diversity + Algorithm-led delivery. Meta находит нужных людей через сигналы самих креативов — не через настройки таргетинга.
✅ Делаем
1 ad set с broad аудиторией → все 12 креативов конкурируют. Advantage+ Audience или Тбилиси 22–58, без интересов.
❌ Не делаем
Отдельный ad set под каждый портрет, возраст, интерес. При $310/мес три ad set = ~$3.40/день каждый — слишком мало для обучения.
